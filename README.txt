하루의 여백 · 플래너

실행 및 업데이트
- ZIP 압축을 풀고 index.html을 브라우저에서 엽니다.
- index.html, style.css, script.js를 같은 폴더에 두세요.
- 기존 버전은 같은 위치의 세 파일을 교체하고 새로고침하세요.
- 같은 브라우저/파일 위치의 기존 할 일, 반복 설정, 날짜 표시를 이어서 사용합니다.

할 일
- 내용과 선택 사항인 시작/종료 시간을 입력해 추가합니다.
- 시작 시간만 지정하거나 시간을 비워둘 수도 있습니다.
- 종료 시간은 같은 날의 시작 시간 이후로 지정합니다.
- 목록은 시작 시간순이며 시간 미정 항목은 뒤에 표시합니다.
- 제목을 클릭하면 내용과 시간을 수정할 수 있습니다.
- 체크로 완료 표시, ×로 삭제합니다.

반복 할 일
- '요일별 반복 할 일 만들기'를 펼쳐 월·수·금처럼 여러 요일을 선택합니다.
- 달력의 선택 날짜부터 적용되며 종료일은 선택 사항입니다.
- 시간도 지정할 수 있고 완료 여부는 날짜별로 독립 저장됩니다.
- 반복 항목 제목을 누르면 '이번 날짜만' 또는 '이 날짜부터 모두' 수정합니다.
- '이번 날짜만'은 내용과 시간을 변경합니다.
- '이 날짜부터 모두'는 내용·시간·요일·종료일을 변경하고 과거 기록은 보존합니다.
- 이 날짜부터 모두 변경하면 이후 날짜에 개별 지정했던 내용/시간은 새 설정으로 통일됩니다.
- 목록에서 ×는 해당 날짜만 제외합니다.
- 반복 설정 목록의 제목은 선택 날짜(시작일 이전이면 시작일)부터 수정합니다.
- 반복 설정 목록의 ×는 확인 후 해당 반복 구간 전체와 완료 기록을 삭제합니다.

날짜 표시 / 기간 일정
- To-do list 아래 '이 날은 어떤 날?'은 체크할 할 일과 별개입니다.
- 내용과 시작일·종료일을 입력합니다. 하루 일정은 두 날짜를 같게 설정합니다.
- 기간 일정은 달력에 이어진 막대로 표시되며 주/월 경계에서 이어집니다.
- 막대 또는 오른쪽 일정 제목을 클릭해 내용과 기간을 수정합니다.
- 오른쪽 ×로 삭제합니다. 여러 날 일정은 전체 기간 삭제를 확인합니다.

저장
- 데이터는 해당 기기 및 브라우저의 localStorage에 자동 저장합니다.
- 서버, 회원가입, 외부 라이브러리, 인터넷 연결 없이 동작합니다.
- 다른 기기와 동기화되지 않으며 브라우저 데이터 삭제 시 사라집니다.
- 파일 경로나 브라우저를 바꾸면 기존 저장 내용에 접근하지 못할 수 있습니다.
- 브라우저가 저장을 차단하면 하단에 안내합니다.

캘린더
- 기기 현지 날짜 기준이며 월요일~일요일을 한 주로 표시합니다.
- 이번 주는 연한 파란색, 오늘은 진한 파란색, 선택 날짜는 테두리로 구분합니다.
- 날짜 버튼에서 방향키로 이동합니다.
- 작은 화면에서는 오른쪽 카드가 달력 아래로 배치됩니다.
